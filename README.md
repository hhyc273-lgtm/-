# البوابات — النسخة الأولية للموقع

موقع دليل محلي لمدينة شهبا، مبني كواجهة ويب ثابتة قابلة للنشر عبر GitHub Pages.

## الملفات
- `index.html` — بنية الموقع.
- `styles.css` — التصميم المتجاوب والألوان والوضع الداكن التلقائي.
- `app.js` — البحث والتصنيفات والمفضلة ونافذة التفاصيل.
- `assets/logo.png` — شعار البوابات الذي أرسله صاحب المشروع.

## تشغيل الموقع محلياً
افتح `index.html` في المتصفح. ولتجربة أفضل يمكن استخدام إضافة Live Server في VS Code.

## النشر على GitHub Pages
1. أنشئ مستودعاً عاماً باسم `al-bawabat`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع المجلد المضغوط فقط).
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظات مهمة
- هذه نسخة واجهة أولية، ولا تحتوي على أسماء محلات حقيقية أو قاعدة بيانات أو لوحة إدارة.
- لم تتم إضافة بيانات محلات تجريبية حتى لا تظهر معلومات غير صحيحة عن منشآت في شهبا.
- زر اقتراح مكان يستخدم بريداً تجريبياً `hello@example.com` ويجب استبداله ببريد المشروع قبل النشر.
- المفضلة محفوظة محلياً في متصفح المستخدم.
- البحث يعمل على بيانات الأماكن التي ستضاف إلى مصفوفة `places` في `app.js`.
- الوضع الداكن يتبع إعداد الجهاز تلقائياً.
- لا تضع كلمات مرور أو بيانات إدارية سرية داخل ملفات الموقع المنشورة علناً.
