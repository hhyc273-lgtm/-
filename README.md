# البوابات — دليل شهبا

ملفات الموقع:
- `index.html` — بنية الصفحة الرئيسية ونافذة تفاصيل المكان.
- `styles.css` — التصميم الأصلي الحجري/الفحمي والذهبي والخلفية العاجية، مع تحسينات الاستجابة والنافذة المنبثقة.
- `app.js` — البحث والتصنيفات والمفضلة وفتح تفاصيل المحل.
- `assets/logo.png` — شعار البوابات الأصلي.

## الإصلاحات
- الإبقاء على ألوان وهوية التصميم الأصلي وعدم استبدالها بالتصميم الأخضر الجديد.
- جعل بطاقة المحل كاملة قابلة للضغط لفتح التفاصيل، مع بقاء زر المفضلة مستقلاً.
- منع تمرير الصفحة الرئيسية أثناء فتح نافذة التفاصيل، والسماح بالتمرير داخل النافذة.
- دعم الإغلاق بزر الإغلاق ومفتاح Escape والضغط خارج النافذة.
- تحسين عرض تفاصيل المحل على الهاتف والشاشات الصغيرة.

## بيانات الأماكن
تحتوي النسخة على المكان الذي تتوفر له بيانات مؤكدة حالياً: «لمعة الذهب». لا توجد أسماء أو عناوين افتراضية مختلقة لبقية الأماكن. أضف الأماكن الأخرى داخل مصفوفة `places` في `app.js` بعد التحقق من بياناتها.

## النشر
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages مع الحفاظ على المسارات كما هي.
